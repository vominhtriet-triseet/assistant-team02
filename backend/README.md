# Personal Assistant Bot - Backend

A lightweight Python backend for a personal assistant bot with basic scheduling capabilities.

## Run

1. **Install dependencies:**
   ```bash
   pip install -r requirements.get (if any)
   ```

2. **Run the backend:**
   ```bash
   python main.py
   ```

3. **Run tests:**
   ```bash
   python -m unittest test_backend.py
   ```

## Features
* **Help Command:** Reply to 'help' with a list of available capabilities.
* **Basic Scheduling:** Contextual framework for managing user schedules.
