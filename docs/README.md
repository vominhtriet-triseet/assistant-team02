# Project Documentation

Thư mục này chứa các tài liệu quan trọng của dự án. Mục đích của bộ tài liệu này là để:
- Lưu trữ các quy chuẩn làm việc chung và phân công vai trò của nhóm.
- Cung cấp tài liệu tham khảo cho các thành viên trong quá trình phát triển dự án.
- Đảm bảo tính minh bạch và dễ dàng theo dõi tiến độ công việc.
